# REPLACE-ME: files to swap

Everything in this folder can be replaced. Put the new file here with exactly
the same name, then push. No code needs to change.

| File | What it is | Used on |
|---|---|---|
| `REPLACE-ME_signature.png` | Signature over the greeting photo. PNG with a transparent background, ink in #3B2A22. | Home |
| `REPLACE-ME_photo-elisa.jpg` | Greeting photo, 3:2 landscape. While this file is missing, the current placeholder photo is shown. | Home |
| `REPLACE-ME_hw-selected-work.png` | Handwritten "Selected Work" above the portfolio cards. Transparent PNG, ink in #3B2A22. | Home |
| `REPLACE-ME_hw-love-notes.png` | Handwritten "Love Notes" in the top-left corner of the reviews. Transparent PNG, ink in #3B2A22. | Home |

The two handwriting slots can also be `.svg` or `.webp` with the same name.
If a handwriting file is missing, its text is shown instead, in the
`--font-handwriting` font (for now Tangerine).
